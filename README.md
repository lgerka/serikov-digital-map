# Карта развития digital — Serikov Coffee

Интерактивная карта работ по сайту serikovcoffee.kz: что уже работает, что нашёл аудит,
что делаем дальше и где проходит граница между digital-маркетингом и контентом.

Открыть: `index.html` в браузере. Ничего собирать не нужно — обычные HTML, CSS и JS без зависимостей.

## Что внутри

| Файл | Что в нём |
| --- | --- |
| `index.html` | Все разделы страницы |
| `assets/styles.css` | Оформление, светлая и тёмная тема, анимации |
| `assets/app.js` | Интерактивная карта, аккордеон аудита, счётчики, тема |

## Разделы

1. **Где мы сейчас** — цифры сайта на 27.09.2026.
2. **Карта работ** — шесть направлений, каждое раскрывается по клику.
3. **Что нашёл аудит** — находки с важностью и решением.
4. **План на три месяца** — три шага до первой рекламы.
5. **Что такое digital-маркетинг** — граница с контентом и SMM, кто за что отвечает.
6. **Что нужно от компании** — доступы, решения, ресурсы.

## Данные

Цифры сняты с боевой базы магазина и проверкой сайта 27 сентября 2026 года.
Репозиторий приватный: внутри внутренние показатели компании.

## Правки

Контент карты лежит одним объектом `BRANCHES` в начале `assets/app.js` — тексты правятся там,
разметку трогать не нужно.
